## Usabilidade antes do beta — 05/11/2026

Revisão dos pontos que podem confundir alunos pouco acostumados com tecnologia, com nove problemas observados, propostas de mudança e 24 prints do projeto executado localmente.

- [Baixar o relatório completo com os prints (ZIP)](https://raw.githubusercontent.com/newthuzz/missao-escola/main/relatorios/missao-escola-analise-beta.zip)
- [Ler o relatório com imagens no GitHub](analise-fluxo-beta/ANALISE.md)
- [Ver todos os prints](analise-fluxo-beta/prints)

Para abrir a versão HTML, baixe e extraia o ZIP e abra `analise-fluxo-beta/ANALISE.html`. Mantenha a pasta `prints` junto do arquivo.

A análise foi feita sobre o código `6957169`, com navegação simulada sem conta. Não é uma pesquisa com alunos reais nem uma confirmação do estado de produção. A publicação deste relatório não aplica as mudanças propostas à interface.
