# Versões do Missão Escola

## Beta local — 05/11/2026

[**Baixar a versão local para teste (ZIP)**](https://raw.githubusercontent.com/newthuzz/missao-escola/main/VERS%C3%95ES/missao-escola-beta-local-2026-11-05.zip)

Este é o mesmo ZIP entregue para avaliação local: build pronta, código-fonte, códigos do Supabase, prints, relatório técnico e instruções.

1. Extraia todo o ZIP.
2. Com Node.js 20 ou superior instalado, abra `INICIAR-LOCAL.bat` no Windows.
3. Acesse **http://localhost:4173**. Mantenha a janela do servidor aberta.

Em outros sistemas, execute `node scripts/serve-local.mjs` na pasta extraída.

Leia `LEIA-ME-TESTE-LOCAL.md` antes de testar serviços externos. Login, Tutor e amigos/ligas dependem das configurações existentes; a conexão com produção não foi validada nesta entrega. Prefira uma conta de teste para usar a sincronização real.

A publicação deste pacote não aplica o código beta ao site. As mudanças continuam empacotadas para avaliação local.

A integridade do arquivo pode ser conferida em [SHA256SUMS.txt](SHA256SUMS.txt).
